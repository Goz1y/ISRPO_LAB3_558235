# FastComments

Расширение для VS Code, которое автоматически генерирует шаблонные комментарии к функциям на C/C++

## Команды и горячие клавиши (по умолчанию)

| Команда | Описание | Клавиши (Win/Linux) |
| "FastComments: Вставить комментарий" | Вставляет шаблонный комментарий в функцию под курсором | "Ctrl+Alt+C" |
| "FastComments: Переключить режим вставки" | Меняет режим: "внутри функции" -> "перед функцией" | "Ctrl+Alt+P" |
| "FastComments: Показать статистику" | Открывает панель с графиками и аналитикой по текущему файлу | "Ctrl+Alt+9" |
| "FastComments: Изменить горячие клавиши" | Открывает меню настройки хоткеев с фильтром по плагину | "Ctrl+Alt+]" |

## Настройки (Settings)

В разделе **Settings -> Extensions -> FastComments** доступны следующие параметры:

*   "fastcomments.commentTemplate": Шаблон комментария. Поддерживает переменные "${functionName}", "${argumentsSignature}", "${argumentsDocs}", "${argumentsNames}".
*   "fastcomments.insertPosition": Куда вставлять комментарий ("before" - перед функцией, "inside" - внутри блока).
*   "fastcomments.enableTelemetry": Включить или отключить сбор локальной статистики.

## Аналитика и Телеметрия

Плагин собирает данные о том, какие функции были задокументированы, и сохраняет их локально в "workspaceState".
При вызове команды "Показать статистику" открывается панель, где отображается:
1. Общее количество функций в файле.
2. Количество функций, задокументированных плагином.
3. Процент покрытия документацией.
4. График сложности функций (по количеству строк кода) и количества параметров.

## Разработка и запуск

1. Установите зависимости:

    npm install

2. Скомпилируйте проект:
